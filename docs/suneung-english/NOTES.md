# Notes

## 학습자 선호
- 한국어로 가르치고 해설한다. 지문과 선지는 수능처럼 영어로 둔다 (요지·주장·목적 유형의 선지만 한국어).
- 하루 20분 세트. 한 세트는 독해 9문항 안팎이다.
- 듣기는 제외한다.
- 목표는 2등급에서 1등급(원점수 90점 이상)이다.

## 운영 원칙
- 평가원·EBS 문제와 지문을 그대로 쓰거나 비슷하게 베끼지 않는다. 모든 지문은 새로 쓴 창작이다.
- "예상 문제"라고 부르지 않는다. 실제 출제를 예측할 수 없으므로 "수능형 연습 세트"라고 부른다.
- 시험일, 문항 수, 시간 같은 사실은 평가원 공식 자료에서 확인한 값만 쓴다 (RESOURCES.md 참고).
- 새 세트는 정답 키를 만든 뒤, 정답을 모르는 독립 검증자가 풀어서 키와 대조한 다음에 내보낸다.
- 세트 결과(유형별 정답률)가 들어오면 다음 주 세트의 유형 비중을 조정한다.
- 용어는 GLOSSARY.md를 따른다 (아직 없음. 사용자가 쓸 수 있게 된 용어만 추가한다).

## 작업 공간 구조와 도구
- `assets/plan.js`: 날짜별 유형 구성·3점 수·강조 유형. 세트를 더하거나 바꿀 때 여기부터 고친다.
- `sets/YYYY-MM-DD.js`: 세트 데이터. 형식은 `assets/SET-FORMAT.md`.
- `lessons/YYYY-MM-DD.html`: `node tools/build-lessons.js`로 plan.js에서 생성하는 얇은 페이지. 손으로 고치지 않는다.
- `assets/set-runner.js`: 타이머·채점·해설·localStorage 저장·결과 복사. `index.html`은 달력.
- 검증: `node tools/validate.js --all`. 블라인드 검증: `node tools/make-blind.js <폴더>` → 검증자가 푼 답을 `node tools/compare.js <답안 폴더>`로 대조.
- 결과는 브라우저 localStorage에만 남으므로, 사용자가 붙여 넣는 결과 요약을 learning-records에 옮겨 적는다.
