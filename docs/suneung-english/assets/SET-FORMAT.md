# 세트 파일 형식 (sets/YYYY-MM-DD.js)

세트 하나는 `sets/YYYY-MM-DD.js` 파일 하나다. 브라우저가 `file://`로 열어도 동작하도록 JSON이 아니라 전역 변수를 대입하는 JS 파일로 쓴다. 파일 전체는 아래 한 문장뿐이어야 한다.

```js
window.CSAT_SET = { ... };
```

검증: `node tools/validate.js sets/YYYY-MM-DD.js` 가 `OK`를 출력해야 한다. 오류가 하나라도 있으면 세트는 완성이 아니다.

## 최상위 필드

| 필드 | 설명 |
|---|---|
| `date` | `"YYYY-MM-DD"`. 파일 이름과 같아야 한다. |
| `dday` | 정수. `assets/plan.js`의 해당 날짜와 같아야 한다. |
| `week` | 정수. plan.js와 같아야 한다. |
| `focus` | 문자열. plan.js의 `focus`를 그대로 복사한다. |
| `intro` | 한국어 1~2문장. 오늘 세트의 구성과 주의점. |
| `tip` | 한국어 2~4문장. 오늘 강조 유형을 푸는 구체적 절차. "~하는 경우가 많다" 같은 출제 통계 주장은 쓰지 않는다. |
| `timeLimitMin` | (선택) 정수. plan.js에 있을 때만 같은 값으로 넣는다. |
| `questions` | 문항 배열. 개수와 유형 순서가 plan.js의 `types`와 정확히 같아야 한다. |

## 문항 객체

| 필드 | 설명 |
|---|---|
| `n` | 1부터 순서대로. |
| `type` | 아래 유형 코드 중 하나. |
| `points` | 2 또는 3. 세트 안의 3점 문항 수는 plan.js의 `three`와 같아야 한다. 3점은 blank, insert, order, summary, implied 중에서 고른다. |
| `stem` | (선택) 발문. 비우면 실행기가 유형별 기본 발문을 쓴다. `match`·`notice`는 반드시 쓴다 (예: `"Harlow Creek Trail Run에 관한 다음 안내문의 내용과 일치하지 않는 것은?"`). |
| `passage` | 영어 지문. 아래 토큰 규칙을 따른다. `order` 유형은 비우고 `given`·`parts`를 쓴다. |
| `given` | `insert`: 주어진 문장. `order`: 주어진 글(1~2문장). `summary`: 요약문 (`(A)`, `(B)` 포함). 그 외 생략. |
| `parts` | `order`만. `{ "A": "...", "B": "...", "C": "..." }` 각 2~4문장. |
| `options` | 문자열 5개. ①~⑤ 순서. |
| `answer` | 1~5 정수. |
| `explanation` | 한국어 2~4문장. 정답의 근거가 되는 지문의 단서(영어 표현을 인용)와, 가장 끌리는 오답이 왜 틀렸는지. 어법은 규칙과 고친 형태, 어휘는 적절한 낱말을 적는다. |
| `vocab` | 문자열 3~8개. `"단어 — 뜻"` 형식. 지문에서 수험생이 모를 법한 것. |

## 지문 토큰

지문은 일반 텍스트이며 HTML 태그를 쓰지 않는다. 단락 구분은 `\n`. 다음 토큰만 허용한다.

| 토큰 | 용도 | 규칙 |
|---|---|---|
| `[BLANK]` | 빈칸 | `blank` 유형에 정확히 1개. |
| `[1]{text}` ~ `[5]{text}` | 번호 밑줄 | `grammar`·`vocab`: 낱말/구 5개. `irrelevant`: 문장 5개 (첫 문장은 번호 없이 도입). 각 번호가 정확히 1번씩. |
| `[P1]` ~ `[P5]` | 삽입 위치 | `insert`에 정확히 각 1개. 문장과 문장 사이에 둔다. |
| `[U]{text}` | 밑줄 | `implied`에 정확히 1개. |

## 유형 코드와 선택지 언어

| 코드 | 유형 | 선택지 | 비고 |
|---|---|---|---|
| `purpose` | 목적 | 한국어 "~하려고" 5개 | 편지·이메일·공지. 발신자·수신자가 드러나게. |
| `mood` | 심경 변화 | 영어 `"nervous → relieved"` 5개 | 서사문. 전환점이 분명하게. |
| `claim` | 주장 | 한국어 문장 5개 | 필자의 당위 주장이 명확한 논설문. |
| `implied` | 함축 의미 | 영어 구 5개 | `[U]{...}` 비유 표현 1개. 글 전체 논지로 풀리게. |
| `gist` | 요지 | 한국어 문장 5개 | |
| `topic` | 주제 | 영어 명사구 5개 | |
| `title` | 제목 | 영어 제목 5개 | 비유·의문문 허용. |
| `match` | 내용 일치 | 한국어 5개 | 가상 인물의 약력. 발문에 이름을 넣는다. 해설에 가상 인물임을 적는다. |
| `notice` | 안내문 | 한국어 5개 | 가상 행사. 날짜·장소·비용·신청 등 항목형. 발문에 행사명을 넣는다. |
| `grammar` | 어법 | `["①","②","③","④","⑤"]` | 틀린 것 정확히 1개. 수일치, 관계사, 분사, 병렬, 대명사, to부정사/동명사, what/that, 형용사/부사, 수동태 등 수능에서 흔한 유형. 나머지 4개는 틀렸다고 오해하기 쉬운 올바른 형태. |
| `vocab` | 어휘 | `["①","②","③","④","⑤"]` | 문맥에 반대되는 낱말 정확히 1개. 앞뒤 문장에 단서가 있어야 한다. |
| `blank` | 빈칸 추론 | 영어 구/절 5개 | 빈칸은 결론 문장이나 핵심 재진술에. 선택지는 길이·문법 형태를 맞춘다. 정답은 지문 표현을 바꿔 말한 것. |
| `irrelevant` | 무관한 문장 | `["①","②","③","④","⑤"]` | 소재는 같지만 논지에서 벗어난 문장 1개. |
| `order` | 글의 순서 | 고정: `["(A) - (C) - (B)","(B) - (A) - (C)","(B) - (C) - (A)","(C) - (A) - (B)","(C) - (B) - (A)"]` | 연결어·대명사·지시어로 순서가 하나로만 정해지게. |
| `insert` | 문장 삽입 | `["①","②","③","④","⑤"]` | 주어진 문장에 this/such/however 같은 단서. 들어갈 자리는 하나뿐이어야 한다. |
| `summary` | 요약문 | `"word …… word"` 5개 | `given`에 `(A)`, `(B)`. 구분자는 ` …… ` (가운뎃점 6개). |

## 길이와 수준

- 지문 100~170 단어 (`notice`는 60~140, `order`는 given+parts 합계 120~190).
- 수능 영어 수준: 교양 비문학(심리, 경제, 과학, 교육, 예술, 환경, 기술, 역사 일반론). 한 지문에 복문 2~3개. 어휘는 고3 수준.
- 주차별 난도: 1~2주차 수능 수준, 3주차 수능 수준에서 빈칸만 약간 더 어렵게, 마무리(4주차)는 쉬운 편.
- 지문의 어조·구성은 수능과 비슷하되 **내용은 전부 새로 쓴다.** 평가원·EBS·교과서·유명 저서의 지문을 옮기거나 가깝게 바꿔 쓰지 않는다. 실존 인물·기업·사건의 사실을 단정하는 문장은 피한다 (일반론으로 쓴다). 안내문·약력은 가상의 이름을 쓴다.

## 정답 배치

- 9문항 세트: ①~⑤가 모두 최소 1번, 어느 번호도 3번을 넘지 않게. 6문항 세트: 어느 번호도 2번을 넘지 않게.
- 텍스트 선택지는 길이를 비슷하게 (가장 긴 것이 가장 짧은 것의 1.8배 이내). 정답만 길거나 구체적이면 안 된다.
